# Аналитика корпоративного обучения IT Resume

Итоговый учебный проект по SQL: https://app.simulative.ru/course/14/721

Клиент `company_id = 1`, период `[2021-07-01; 2022-05-01)`.
Это историческая учебная выборка, выгруженная 03.10.2026 из базы Simulative.

## Структура проекта

- `report.docx` — основной отчёт с результатами, графиками, выводами и полным SQL.
- `sql/` — SQL в отдельных файлах.
- `results/` — рассчитанные агрегаты CSV и результаты независимой проверки.
- `metabase/` — самостоятельные SELECT-запросы для Metabase без временных представлений.


## Запуск на учебной базе PostgreSQL

В одном сеансе выполните `sql/00_prepare.sql`, затем нужные запросы `01`–`12`.
Скрипт создаёт только временные представления. Все исходные таблицы читаются, но не изменяются.
В Metabase выбирайте базу Simulative и запускайте файлы `metabase/` по отдельности.
Параметры компании и периода находятся в начале запроса. Для воспроизведения отчёта не меняйте их.

## Проверка на локальном снимке

Исходная обезличенная выборка хранится только локально в `source/` и не опубликована в репозитории.
Для воспроизведения выгрузки используйте `export_source.sql` в Metabase и сохраните CSV
как `source/company1-export.csv`. Структура использованных таблиц — `source/schema.csv`.

Установите `psycopg2-binary`, настройте `PGHOST`, `PGPORT`, `PGUSER`, `PGDATABASE` и при необходимости
`PGPASSWORD`. Затем `python analyze.py` и `python verify.py`. Значения по умолчанию предназначены
только для локального проверочного PostgreSQL на `127.0.0.1:55439`.
Скрипт загружает данные во временные таблицы и закрывает транзакцию через rollback.

## Основные исправления

1. Один клиент и явный исторический период вместо смешения всех пользователей и необязательных фильтров.
2. Числа и интерпретации по каждому аналитическому блоку.
3. Первые решения за всю доступную историю до конца периода, без повторного учёта старых решений.
4. Активация с полными окнами наблюдения.
5. Когортная сетка: ноль активности отдельно от ещё не наблюдавшегося месяца.
6. Разделение охвата каталога домашних заданий и прогресса отдельных студентов.
7. Попытки до первого успеха с определённым порядком событий, оговоркой о нерешивших и размерами групп.
8. Проверка гипотез без утверждений о доказанной причинности.

В отчёте сохранены основные направления исходного исследования; повторяющиеся KPI объединены.
Объём практики не считается временем обучения или денежной окупаемостью.
